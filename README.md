# JAGUAR TEC
## NASA Space Apps Challenge 2026

**Space Mission Stress Monitoring and Mental Wellness Platform**

### Project Description
JAGUAR TEC is an interactive software prototype designed to monitor psychological stress, support emotional self-regulation, and assess individual and team well-being during simulated space missions, with potential future applications in real space missions.

### Main Features
- **Mission Registration:** Create and manage space missions.
- **Crew Registration:** Register individual crew members.
- **Individual Assessment:** Record stress, anxiety, fatigue, and other self-reported indicators.
- **Team Monitoring:** Track team communication, cohesion, and coordination.
- **Galaxy Flow:** Interactive space-themed game designed to encourage concentration and engagement.
- **Space Relaxation:** Guided breathing exercises and relaxing audio.
- **Mission Dashboard:** Review individual and team assessment records.
- **Contact:** Access project team information.

### Scientific Purpose
The project aims to investigate digital tools for stress monitoring and emotional self-regulation in space mission environments. Its effectiveness requires experimental validation.
